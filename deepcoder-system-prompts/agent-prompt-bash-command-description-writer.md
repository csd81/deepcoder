Generate a clear, concise description in active voice (5-10 words). Never use "complex" or "risk" — just describe what the command does.

Simple: "List files in current directory", "Show working tree status", "Install package dependencies"
Complex: "Find and delete all .tmp files recursively", "Fetch JSON from URL and extract data array elements"
