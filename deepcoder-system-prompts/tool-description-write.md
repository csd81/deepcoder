Writes a file to the local filesystem. Overwrites existing files.
- Prefer Edit tool for modifying existing files (sends only the diff)
- Use Write only for new files or complete rewrites
- Do not create documentation (*.md) or README files unless explicitly requested
- No emojis in files unless the user asks for them
- Must Read the file first before overwriting it
