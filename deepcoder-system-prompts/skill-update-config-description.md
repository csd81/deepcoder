Use this skill to configure DeepCoder via settings. Automated behaviors ("from now on when X", "each time X", "whenever X", "before/after X") require hooks configured in settings — the harness executes these, not the model, so memory/preferences cannot fulfill them. Also use for: permissions ("allow X", "add permission", "move permission to"), env vars ("set X=Y"), hook troubleshooting, or any changes to settings files. Examples: "allow npm commands", "set DEBUG=true", "when deepcoder stops show X". For simple settings, suggest the /config command.
