Use before non-trivial implementations to explore the codebase and design an approach for user approval.

Use when:
- New feature with meaningful functionality
- Multiple valid approaches exist
- Changes affect existing behavior/structure
- Architectural decisions needed
- Multi-file changes (2-3+ files)
- Unclear requirements needing exploration
- User preferences matter

Skip for: single-line fixes, obvious bugs, very specific instructions, pure research.

Requires user approval to enter plan mode. When in doubt, err on the side of planning.
