Creates a structured task list for the session.

Use when:
- Complex multi-step (3+ steps), non-trivial tasks
- Plan mode
- User explicitly requests it or provides multiple tasks
- After receiving new instructions

Skip when:
- Single straightforward task
- Purely conversational or informational

Fields: subject (imperative), description, activeForm (present continuous, optional). All tasks created as "pending".
