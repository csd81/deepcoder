Dream: reflective pass over memory files. Synthesize recent learning into durable, well-organized memories.

**Phase 1 — Orient:** List memory dir, read index, skim existing files
**Phase 2 — Gather:** Session logs (recent 1-3 days), drifted memories, narrow transcript searches
**Phase 3 — Consolidate:** Write/update memory files. Merge signal into existing files, convert relative dates to absolute, delete contradicted facts
**Phase 4 — Prune and Index:** Keep index under ~25KB, one line per entry under ~150 chars. Remove stale pointers, resolve contradictions

Return a brief summary of what changed.
