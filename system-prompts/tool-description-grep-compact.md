Content search built on ripgrep. Prefer this over `grep`/`rg` via Bash — results integrate with file links.
- Full regex syntax (e.g. "log.*Error", "function\s+\w+")
- Filter with `include` (e.g. "*.tsx") or `path` directory
- Returns matching file paths and line numbers
