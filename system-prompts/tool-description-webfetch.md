Fetches content from a URL and returns it. Read-only, no file modification.
- URL must be fully-formed; HTTP auto-upgraded to HTTPS
- Prefer MCP-provided web fetch tools if available
- Includes 15-min cache for repeated URLs
- For GitHub URLs, prefer `gh` CLI via Bash instead
- Results may be summarized for large content
